# Bug Fix Log — BITS Digital CodeForge V1.0

Every defect below was reproduced against the original `BITS_Digital_CodeForge_Challenge.html` in headless Chromium, using generated spreadsheets from `tests/fixtures/`. "Evidence" quotes what the original actually did. Each fix is covered by an automated test (unit test in `tests/core.test.cjs` or end-to-end test in `tests/e2e.py`); test names are given in the last column.

The two bugs flagged in the original source comments are #3 and #24.

## Upload and parsing

|---|---|---|---|---|---|

Evidence: `Avg NaN`, median `79.9`. | Text cells stay strings; `reduce((a,b)=>a+b)` concatenates. | Marks are parsed strictly: numeric text is accepted, anything else (e.g. “AB”, “NC”) is reported per row. | Unit: *numeric IDs and course codes…*, *messy workbook…* |

| 15 | Duplicate student IDs graded twice | Evidence: `2024A7PS0010P` exported twice; `2024A7PS0011P` exported with both 58 and 66. | No duplicate detection. | Per course, identical duplicates count once (flagged to check); conflicting marks are excluded until the file is fixed. | 16 | Blank BITS ID exported as `undefined` | Evidence: CSV row `undefined,70,A-`. | Missing cells produce `undefined` keys. | Rows without an ID are excluded and listed. | Unit + E2E messy-sheet tests. |
| 17 | Blank course creates an empty course option | Evidence: an empty entry in the course list. | Same as #16. | Rows without a course are excluded and listed; course-name case variants (“cs f111”) are merged and reported. | Unit + E2E messy-sheet tests. |
